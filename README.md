# Goku Wallet

Goku Wallet merupakan sistem pengelolaan keuangan mahasiswa berbasis website yang dikembangkan menggunakan framework Laravel. Aplikasi ini membantu pengguna mencatat dan memantau pemasukan serta pengeluaran keuangan.

## Fitur Aplikasi
- Registrasi dan login pengguna.
- Dashboard keuangan.
- Pencatatan transaksi.
- Pengelolaan pemasukan dan pengeluaran.
- Riwayat transaksi.

## Teknologi
- PHP
- Laravel
- MySQL
- HTML
- CSS
- JavaScript
